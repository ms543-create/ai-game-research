# Roadmap

## Phase 1 — Establish the baseline

- Preserve a small playable trivia/word-search mechanic.
- Record its input behavior, scoring rules, test coverage, and performance.
- Select one coding-agent feature experiment and set acceptance criteria.

**Exit condition:** a reproducible baseline commit and a feature test plan.

## Phase 2 — Test individual capabilities

- Run the code feature experiment.
- Compare a synthesized and generated sound pack.
- Import and optimize one generated 3D prop.
- Record generation attempts, cleanup time, costs, and failure cases.

**Exit condition:** usable artifacts and documented decisions, even if a candidate is rejected.

## Phase 3 — Choose a delivery stack

- Compare the simplest viable web approach with one engine alternative.
- Measure the same interaction and assets on the reference hardware.
- Select the stack based on the playable experience and maintenance burden.

**Exit condition:** a written engine decision supported by comparable tests.

## Phase 4 — Build a polished slice

- Integrate the chosen feature, audio, and visual assets.
- Add onboarding, settings, keyboard support, and restart behavior.
- Test with players who have not seen the project before.
- Address observed failures before expanding content.

**Exit condition:** a shareable playable slice and an honest account of what AI contributed and what required human work.
